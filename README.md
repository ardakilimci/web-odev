# Kişisel Portfolyo Web Sitesi

Bu proje, Batman Üniversitesi Bilgisayar Mühendisliği Bilgisayar Mühendisliğine Giriş dersi ödevi kapsamında geliştirilmiştir.

## Kullanılan Teknolojiler
- HTML5
- CSS3 (Flexbox & Grid, CSS Animations)
- JavaScript (Form Doğrulama & Dinamik İçerik Gösterimi)

## Geliştiren
- **Ad Soyad:** Arda Kilimci
- **Bölüm:** Bilgisayar Mühendisliği (1. Sınıf)
